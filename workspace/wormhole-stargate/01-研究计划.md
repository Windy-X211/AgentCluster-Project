## 0. 定位与一次性的方向裁定

**用户诉求 → 本研究题目的降维映射**

| 用户表述 | 对应的物理学概念 | 本研究是否处理 |
|---|---|---|
| 星门 | 可穿越虫洞（traversable wormhole）作为两个遥远时空区域间的类捷径几何（喉部 + 双口） | 是（几何层面） |
| 虫洞稳定装置 | 维持喉部开放所需的负能量密度分布（exotic matter distribution）及可施加的约束构型 | 是（理论构型层面） |
| 研发 | 定量可行性评估（预算差距分析），**不是**工程样机研制 | 是（边界内） |

**裁定理由（为什么必须降维）**：
1. 当前物理框架下不存在任何已知机制能提供维持宏观虫洞所需量级的负能量；直接以"研发装置"为研究问题，将没有任何可检验假设，也无法定义验收标准——研究必然失败。
2. 但"差距到底有多大、卡在哪条理论上限上"是一个**完全可计算、可被推翻**的问题：它只需要已有文献公式 + 解析量级估计 + 敏感性分析，不需要新物理。
3. 该问题具有排他性价值：它是任何工程路线的必要前置否决/放行判据。若差距为几十个数量级，则"装置"路线在可预见未来不具备研究价值——这个结论本身就是有效产出。

**结论：本研究定位为「负能量预算差距评估（negative-energy budget gap analysis）」，不做装置设计。**

## 1. 研究问题

### 1.1 候选问题与排序

| 编号 | 候选问题 | 价值 | 可行性 | 排序 |
|---|---|---|---|---|
| **Q1（主线）** | 在 Morris–Thorne 型可穿越虫洞几何 + 半经典量子场论负能量源框架下，维持喉部半径 b₀ 开放所需的负能量密度与总量，与已知物理机制（Casimir 效应、压缩真空、动态 Casimir、弯曲时空重正化能动张量）所允许的负能量上限之间，相差多少个数量级？该差距由哪一条量子能量条件封顶？ | 高：给出可行性边界，结论可被反驳 | 高：纯解析估计 + 文献参数对比 | **保留** |
| Q2 | 虫洞喉部的径向/微扰稳定性在何种物态方程与边界条件下成立；不同稳定机制的稳定性判据如何对比 | 中 | 中：依赖 Q1 的负能量源结论，且易滑向纯形式推导 | 降为 Q1 的**技术子问题**（写入 03 方案），不单列 |
| Q3 | 量子引力的熵界（Bousso bound）/ ER=EPR 类猜想对宏观"星门式"连接的限制 | 高（若成立） | 低：依赖未完成的量子引力理论，验收标准无法定义，无法判定对错 | **砍掉**（仅在 02 文献综述中作为"理论前沿与未决争议"一段，不做定量） |

**只保留 Q1 作为主线。** 砍 Q3 的理由：一个无法定义"什么算完成"的问题会污染整条链路；砍 Q2 单列的理由：避免团队在无负能量源判据的情况下做形式化稳定性推导（形式推导可以任意写，不可证伪）。

### 1.2 主线问题正式表述

> **RQ**：设可穿越虫洞的喉部半径取 b₀（取值档位见 §3.3），在广义相对论 + 半经典量子场论近似下，(a) 维持该几何所需的最小负能量密度剖面与负能量总量（折算为等效质量 M_neg）是多少；(b) 已知物理机制可提供的负能量密度上限是多少；(c) 二者的比值在 b₀ 与机制维度上的标度关系与数量级差距是多少；(d) 该差距是否由某条量子能量条件（ANEC / AANEC / Ford–Roman / 量子不等式 QI）给出不可逾越的上界。

**可反驳性声明**：若文献调研发现某种已确证的机制（例如大尺度压缩真空或动态 Casimir 阵列的相干增强）能把差距压缩到可讨论范围，则结论方向必须相应修改。本研究不预设"不可能"这一结论。

## 2. 边界定义

### 2.1 研究范围（做什么）

- R1 可穿越虫洞的几何描述与"可穿越性"的定量判据（无事件视界、喉部存在、潮汐加速度上限）。
- R2 维持喉部所需的负能量剖面与总量的解析估计（量级 + 标度律）。
- R3 已知负能量机制的可达上限梳理与横向对比。
- R4 量子能量条件对"负能量总量"的封顶作用（是否存在硬上界）。
- R5 差距的数量级结论 + 对假设的敏感性分析 + 可信度分级。

### 2.2 明确不做（Out of Scope）

- ❌ 不做装置工程实现：材料、结构、能量供给、控制回路、建造路线图。
- ❌ 不做时间旅行与闭合类时曲线（CTC）的存在性主张。
- ❌ 不做"传送"生物医学效应、信息协议、通信编码。
- ❌ 不做完整量子引力理论推导（不引入弦论/圈量子引力的具体模型作为计算依据，只在讨论中提及）。
- ❌ 不做数值相对论模拟（本阶段不做，理由：解析量级估计已足够支撑 Q1；若 03 阶段证实解析估计不可判定，再以"建议"形式提出增设，不得擅自扩大）。
- ❌ 不渲染、不使用"星门已可工程化"类断言。

### 2.3 关键概念的操作性定义

1. **可穿越虫洞**：静态、球对称、具有最小面积面（喉部，半径 b₀）且无事件视界、允许双向类光/类时测地线通过的度规解。潮汐加速度上限取 **10 g**（≈98 m/s²，单位长度）作为"可通行"门槛——**注意：此阈值为本研究的人为工作假设，非物理学定律，须在论文方法节显式声明**。
2. **负能量密度**：能动张量满足局域能量条件违背，即 T_μν u^μ u^ν < 0 的观测者能量密度。
3. **负能量总量**：E_neg = ∫ ρ_neg dV（ρ_neg < 0 部分的空间积分），以焦耳与等效质量 M_neg = |E_neg|/c² 双单位呈现，并给出太阳质量 M⊙ 对照。
4. **单位制**：理论推导用几何单位 G = c = 1；所有终值必须恢复 SI，并给出普朗克单位对照（便于量纲直觉判断）。
5. **能量条件族**：NEC（零能量条件）、ANEC（沿类光测地线的平均零能量条件）、AANEC（非时序平均零能量条件）、Ford–Roman 不等式、量子不等式 QI——各自定义各一句话写在 02 的术语表中，03 中给出其作为"上界工具"的使用方式。
6. **"差距"（gap）**：以无量纲比值 R = E_neg^required / E_neg^available 表示，结论以 log₁₀ R 表达。**禁止**只写"巨大差距"这类不可检验的表述。

### 2.4 假设前提（待验证假设，编号供下游引用）

- **H1**：半经典近似（量子场在经典弯曲背景上）在喉部尺度对能量密度的**符号**给出正确判断。——*待验证；风险：UV 行为与量子不等式可能在喉部尺度彻底破坏该近似。*
- **H2**：Morris–Thorne 静态族足以代表"最佳情形"，即不引入人为有利的奇异物质薄壳等额外自由假设。——*待验证。*
- **H3**：量子能量条件给出的上界可作为"物理可达上限"使用，且该上界在所需尺度/时标成立。——*待验证；若文献存在分歧，则按区间而非单点处理。*
- **H4**：数量级结论对重正化方案与物态方程细节不敏感（即结论方向不因参数在合理范围内的变动而反转）。——*由 04 的敏感性分析检验。*

- 文献时间窗：经典结果（1970s–1990s，Morris–Thorne 及其后续）+ 主体 2000–2025。
- 语言：英文为主，中文补充；语言不限但须可溯源。

## 4. 成功标准（什么算"研究完成"）

**完成 = 同时满足**：
1. 给出至少 **1 条显式判据**，形式为 `log₁₀ R = f(b₀, 机制)`，并代入 §3.3 全部档位给出数值表；
2. 明确指出是否存在**量子能量条件级别的硬上界**（存在 / 不存在 / 文献分歧），并给出依据来源；
3. 给出结论对 H1–H4 的**敏感性矩阵**与**可信度分级**（高/中/低）；
4. 结论方向如实报告——"差距 N 个数量级"与"差距可被压缩到可讨论范围"是同等合格的结论，**不得为结论预设立场**。

**判定"证据不足、需缩减范围"的情形（触发即降级）**：
- 若 02 显示文献对负能量上界**无共识**（例如量子不等式在不同时空/物态下给出相反方向），则 S3 只做区间估计，并把论文定位从"可行性评估"降级为"上界区间梳理与开放问题识别"；
- 若 02 显示 H1（半经典符号判断）在关键尺度不成立，则删除所有定量差距结论，改为定性结论 + 明确列出"需要什么新理论才能回答"；
- 若某一档 b₀ 所需负能量与已知机制差距小于 10²，则必须把该档位单独升级为"重点核查对象"（这正是可能的反例，不能忽略）。

**明确不算成功**：只输出定性叙述"虫洞需要负能量，因此不可行"；无论文级可复算表格；把结论建立在无法溯源的引用上。

方向已锁：本研究**不研发装置**，而是回答"维持可穿越虫洞所需的负能量，与已知物理机制可提供的负能量，相差多少个数量级，卡在哪条量子能量条件上"。文献调研员的第一要务是把"所需"与"可达"两侧的**可溯源数值**摆平，并如实呈现分歧与反面证据。
