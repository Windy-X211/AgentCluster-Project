# AgentCluster 智能体集群

> **用自然语言描述你的团队，在画布上把它们连成一张协作网——本地运行、数据自持、能力持续扩展。**

AgentCluster 是一个本地优先的多智能体编排平台，将「组团队、派活儿、协作交接」这一套管理学原样搬到 AI 身上。通过可视化画布编排智能体集群，实现复杂任务的协同解决。

## ✨ 特性

### 🎨 画布编排
- **无限画布**：自由拖拽节点，创建复杂的智能体网络
- **可视化协作**：节点代表智能体，连线代表成果流向
- **串行/并行执行**：灵活切换执行模式
- **拖拽优化**：鼠标移出画布边界仍能平滑拖动

### 🤝 A2A 消息协议
- **自研 a2a-lite 协议**：结构化信封消息系统
- **任务接力**：智能体间自动传递任务和成果
- **讨论机制**：`cluster.discuss` 支持多智能体协作讨论
- **消息可视化**：对话中实时展示消息流转

### 🔧 三类能力扩展
1. **命令工具**：文件读写、命令执行、长运行进程
2. **技能系统**：小说创作、角色扮演等专业技能
3. **插件生态**：浏览器控制、SMTP 邮件、HTTP 请求

### 🔒 本地优先
- **数据自持**：全部数据存储在本地 JSON 文件
- **隐私安全**：参数加密，密钥永不出本地
- **离线运行**：无需依赖外部服务

### 🎯 智能感知的运行时
- **意图分类**：快慢双通道意图识别
- **自动验证**：独立验证器确保任务完成度
- **感知范围配置**：link 感知（仅邻居）或 global 感知（画布全体）

## 🚀 快速开始

### 环境要求
- Python 3.13+
- Node.js 20+
- Windows 系统

### 安装

1. **克隆项目**
```bash
git clone https://github.com/Windy-X211/AgentCluster-Project.git
cd 智能体集群
```

2. **启动后端**
```bash
cd backend
pip install -r requirements.txt
python main.py
```
后端将在 `http://127.0.0.1:8870` 启动

3. **启动前端**
```bash
cd frontend
npm install
npm run dev
```
前端将在 `http://localhost:5173` 启动

4. **一键启动**（Windows）
双击 `start.bat` 自动启动前后端和托盘程序

## 📖 使用指南

### 四步搭建集群

1. **描述你的团队**
   用自然语言描述角色分工，例如："产品经理 + 程序员 + QA"

2. **编排师自动搭建**
   内置编排师智能体自动创建智能体、编写提示词、建立连线

3. **运行整队协作**
   启动画布，各成员通过 A2A 消息接力工作

4. **迭代进化**
   随时调整角色、连线、感知范围，集群越用越顺手

### 核心功能

#### 画布操作
- **节点拖拽**：左键拖动智能体节点
- **连线创建**：拖拽节点间的连线建立协作关系
- **右键菜单**：编辑智能体 / 发送消息测试 / 感知范围配置
- **运行控制**：单节点运行、集群整体运行

#### 对话界面
- **流式输出**：实时显示智能体思考和执行过程
- **消息溯源**：每条回复清楚标注来源智能体
- **集群模式**：与整个集群对话，或指定单个智能体

#### 智能体配置
- **系统提示词**：自定义智能体行为和角色
- **能力绑定**：关联命令、技能、插件
- **触发规则**：配置任务触发条件
- **感知范围**：link（仅连线邻居）或 global（画布全体）

## 🏗️ 架构

```
┌─────────────────────────────────────────┐
│ Vue 3 SPA 前端                          │
│ - CanvasBoard 无限画布                 │
│ - MainChat 流式对话                     │
│ - AgentEditDialog 智能体配置            │
└─────────────────┬───────────────────────┘
                  │ HTTP + SSE
┌─────────────────▼───────────────────────┐
│ FastAPI 后端 (localhost:8870)           │
│ - /api/agents 智能体管理                │
│ - /api/canvases 画布管理                │
│ - /api/conversations 对话管理           │
└─────────────────┬───────────────────────┘
                  │ 调度 + function calling
┌─────────────────▼───────────────────────┐
│ Core Engine (backend/core)              │
│ - agent_runtime 运行时引擎              │
│ - a2a 消息协议                          │
│ - commands 工具链                       │
│ - intent_classifier 意图分类            │
│ - validator 独立验证器                  │
└─────────────────┬───────────────────────┘
┌─────────────────▼───────────────────────┐
│ 扩展层                                  │
│ - 插件：浏览器/SMTP/HTTP               │
│ - 技能：小说创作/角色扮演               │
│ - 存储：AppData JSON + 加密             │
└─────────────────────────────────────────┘
```

**后端**

**前端**

- TypeScript 5.5+
