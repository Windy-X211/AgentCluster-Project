# 项目立项书：Chrono Shooter（时序回溯 FPS）

## 一、游戏概述
- **游戏名称**：Chrono Shooter（时序回溯射手）
- **游戏类型**：第一人称射击（FPS）+ 时间操控
- **核心创意**：玩家可以按 Q 键倒流时间 3 秒，所有子弹轨迹、敌人位置、玩家自身全部回退到 3 秒前的状态，创造"试错-修正-再战"的独特战术循环
- **目标平台**：PC 浏览器（双击 HTML 即可运行）
- **技术栈**：Three.js (r128) + HTML5 + JavaScript，单文件交付

## 二、核心卖点
1. **时间回溯机制**：传统 FPS 没有的核心创新，玩家可以撤销错误走位、重置不利局面
2. **霓虹赛博朋克视觉**：暗色竞技场 + 发光网格地面 + 粒子特效 + Bloom 后处理
3. **波次生存模式**：逐波递增的敌人压力，配合时间回溯形成深度策略
4. **零安装即玩**：单个 HTML 文件，双击浏览器打开即可

## 三、受众分析
- 核心受众：喜欢快节奏 FPS + 创新机制的玩家
- 次要受众：对时间操控类玩法感兴趣的休闲玩家
- 体验时长：单局 5-15 分钟
