# 网络小说创作

## 何时使用

当用户要求创作网络小说、人物设定、世界观构建、情节设计、章节撰写或文学编辑时使用此技能。

**不要用在**：散文、论文、技术文档、剧本或诗歌（这些有各自的技能）。

## 工作流程

按以下顺序与用户协作，每一步完成后等待用户确认/修改再进入下一步：

### 第 1 步：故事骨架（用户确认）

输出以下内容：

- **一句话概览**：3-5 句讲清"谁在什么处境下做什么，结果如何"
- **核心冲突类型**：玄幻升级 / 都市逆袭 / 悬疑推理 / 科幻末世 / 历史穿越 / 言情甜宠 …
- **目标读者画像**：男频 / 女频 / 年龄层 / 核心爽点
- **篇幅预估**：中短篇（<50 章）/ 长篇（50-200 章）/ 超长篇（200+）

### 第 2 步：世界观构建（用户确认）

- **时代背景**：古代 / 现代 / 近未来 / 远未来 / 架空
- **地理 & 社会结构**：国家、阶层、重要势力
- **核心法则 / 金手指体系**：修炼等级 / 魔法分类 / 科技水平 / 特殊设定
- **关键 NPC & 势力阵营**：3-5 个最重要的对立 / 盟友阵营

### 第 3 步：主要人物设定（用户确认）

每个主要角色包含：

- 姓名 / 年龄 / 外貌描写（50-80 字）
- 性格关键词（3-5 个）
- 背景故事（100-150 字）
- 动机与秘密（他最想要什么 / 隐藏了什么）
- 人物弧光（故事中性格将如何变化）

### 第 4 步：分卷大纲（用户确认）

- **三幕式结构**：起（20%）→ 承转（50%）→ 合（30%）
- 每卷核心事件、关键转折、高潮场景
- 每卷结尾的"钩子"（悬念 / 反转 / 新疑问）
- 主角在每卷结束时的成长

### 第 5 步：逐章撰写

- 每章 **2000-3500 字**
- 开头 200 字内必须有冲突或悬念
- 对话占比 30%-50%，推动剧情而非闲聊
- 用"展示"代替"告知"——动作、表情、环境细节代替形容词
- 章节结尾留钩子
- 写完一章后自动提供：上一章摘要 + 本章要点 + 下一章预告

## 写作风格

- 文字简洁有力，避免冗余修饰
- 紧张场景用短句密集，抒情/描写适当放慢
- 适度使用比喻和意象，不堆砌辞藻
- 主角视角优先，读者代入感第一
- 每 5000 字自检：删掉无信息量的形容词

## 输出格式

- **分卷大纲**：Markdown 标题 + 列表
- **人物设定**：表格或卡片式
- **章节正文**：直接输出正文，每章标题为 `## 第 N 章 章节名`
- **编辑反馈**：单独一节 `--- 编辑视角 ---` 列出问题和建议

## 扩展资源

- 参考网文常见金手指套路：`references/cheat-sheet.md`（如存在）
- 章节风格模板：`assets/chapter-template.md`（如存在）

## 安全 & 边界

- 不写违法、极端暴力或色情内容
- 用户明确要求"跳过确认、直接写"时也要在每卷/每 10 章节点停一下让用户确认方向
- 写完后主动问："要不要重写某段 / 调整剧情 / 加新角色？"
